把某个地形点位的真实截图放进这里，网站会自动优先展示实拍图（最多 6 张）。

目录命名规则：
    assets/terrain/<地形点位id>/1.jpg
    assets/terrain/<地形点位id>/2.jpg
    ...

地形点位 id 见 data-v4.js 中 terrains 数组的 id 字段，例如：
    is_br1  →  M城南桥（主卡桥点）
    is_ah1  →  军事基地雷达山顶
    ds_hs1  →  皮卡多拳击馆
    rd_hs1  →  荣都高层公寓

只要放进去图片并刷新网页，右侧面板的 360° 程序化视图会自动切换成实拍图 + 多视角缩略图。
