### 一张地图，一整局思路

**信号圈**将地图情报与对局规划连成一条流程：看清资源与地形，标出航线和落点，推演可能的圈形，再把方案交给队友。

它适合赛前讨论、副屏查图和赛后复盘。界面以藏青黑、米白和信号红建立层级；地图保留原有色彩，红色聚焦关键动作与圈形信息。当前应用界面为中文。

### 核心能力

| 环节 | 你可以做什么 |
| :--- | :--- |
| **读图 / Intelligence** | 切换三张地图，搜索点位，用「跳点 / 找车 / 进圈」预设切换图层，组合房群、热区、载具及 19 类地形标注；侧栏可收起。 |
| **落地 / Drop planning** | 选择打法、绘制航线，获取跳点评分与拥堵估算；找车转移优先比较安全分，城区均有风险时尝试补充边缘房备选。 |
| **转移 / Rotation** | 标记落点，在圈内拖动位置、用手柄调整半径，查看进圈目标、示意路线与队伍分工；出发提醒随所选路线同步。 |
| **推演 / Zone scenarios** | 在几何约束内采样 600 个候选圆心，结合水面、物资和掩体等因素显示候选区域。 |
| **协作 / Share** | 分享航线、圈形、落点、打法、圈号与队伍设置，打开后继续规划；兼容旧链接，支持导出「沙盘志」PNG 方案卡。 |
| **复盘 / Review** | 保存实际圈形，回溯候选区命中与偏差；积累足够相邻圈样本后，尝试调整本机模型权重。 |

此外还提供职业运营思路手册、右键收藏、程序化 360° 地形示意、标记去重叠、视口裁剪与键盘缩放。

收藏按地图分别显示。没有地图信息的旧版收藏保留在「待归类收藏」中，切换到对应地图后可手动归入。

### 四步完成一次规划

1. **选打法，画航线。** 在「游戏模式」比较推荐跳点，查看估算拥堵分布。
2. **定落点，找载具。** 选择推荐点或放置大头针，检查附近转移资源。
3. **确认圈形，讨论路线。** 将参考圈拖到合适位置，再查看推演与进圈建议。
4. **整理队伍分工，分享方案。** 将地图局面复制为链接，或导出方案卡发给队友。

### 快速开始

需要现代桌面浏览器，以及 Python 3 或 Node.js 中的任意一种。推荐使用本地 HTTP 服务，以支持地图像素读取与方案卡导出。

```bash
git clone https://github.com/Jul11us/signal-zone.git
cd signal-zone
python -m http.server 8642 --bind 127.0.0.1
```

打开 **[http://127.0.0.1:8642](http://127.0.0.1:8642)**。

### 数据与边界

**圈形推演是讨论工具。** 候选区来自启发式评分，分值是模型内部相对权重，未经真实对局准确率验证。参考半径包含 PUBG PC 实测参考与估算；几何约束依赖输入圈形和这些参数，不能保证手游实际下一圈。航线拥堵也是静态模型估算。

路线为参考点位之间的示意折线，尚未校验道路、水域和山体通行。估时按步行 5.8 m/s、载具 19.5 m/s，并计入标出的取车、搜索和观察等停留时间；安全和资源分值是模型参考分。

点位、资源评级、载具和运营建议为人工整理的参考数据，可能随版本变化。职业手册用于理解运营思路，不替代当前官方赛事规则。当前 360° 视图为程序化地形示意；仓库未附地形实拍照片，可按 [素材目录说明](assets/terrain/README.txt) 自行扩充。

**规划保存在你的浏览器。** 收藏、复盘记录和校准权重使用 `localStorage`，当前应用没有账号系统或业务后端。清除浏览器站点数据会丢失这些本机记录。分享链接将规划编码进 URL，任何获得链接的人都能读取和恢复它；编码不等于加密。

`localhost` 和 `127.0.0.1` 链接仅指向打开者自己的电脑。跨设备分享时，请先使用队友可以访问的部署地址；应用会提示本机链接的访问限制。
